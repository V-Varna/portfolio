# Varna Portfolio (React)

This is a personal portfolio project built with Create React App, modular CSS, and Tailwind CSS. It features:

- Modern, responsive UI
- Modular React components (Header, Hero, Expertise, Experience, Projects, Contact, Footer)
- Tailwind CSS and custom CSS modules
- Swiper.js or React Responsive Carousel for carousels
- React Icons for iconography
- EmailJS for contact form integration
- PWA support (offline, manifest, favicon)
- Google Fonts (Raleway)
- Accessibility best practices

## Getting Started

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the development server:
   ```sh
   npm start
   ```
3. Build for production:
   ```sh
   npm run build
   ```

## Customization
- Replace placeholder images and text with your own content.
- Update EmailJS config in the contact form component.

## Deployment
- Ready for deployment on Vercel, Netlify, or any static hosting.
